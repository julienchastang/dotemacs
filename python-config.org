* Python

1. Create a project virtual environment if it does not exist:
   ~python3 -m venv .venv~
2. Create a ~.envrc~ in the project root:
   #+begin_src sh
   source .venv/bin/activate
   #+end_src
3. Authorize direnv:
   ~direnv allow~
4. Install project dependencies:
   - If the repository is an installable Python project (~pyproject.toml~ or ~setup.py~), use ~python -m pip install -e .~.
   - If development extras are defined, use ~python -m pip install -e ".[dev]"~.
   - If the repository provides ~requirements.txt~, use ~python -m pip install -r requirements.txt~.
   - For a standalone script repository without packaging metadata, install its required dependencies directly.
5. Install development tools not already provided by the project:
   ~python -m pip install basedpyright ruff pytest~
   Install ~python-lsp-server~ only if you need a fallback language server.
6. Verify the environment:

   #+begin_src sh
   which python
   which basedpyright-langserver
   python -m pytest
   #+end_src

7. Open a Python file in Emacs. Verify the environment with:

   #+begin_src emacs-lisp :tangle no
   (getenv "VIRTUAL_ENV")
   (executable-find "python")
   (executable-find "basedpyright-langserver")
   #+end_src

8. Verify Eglot with ~M-x eglot-current-server~. Reconnect with ~M-x eglot-reconnect~ if necessary.

Direnv handles activation when entering the project directory. Manual activation is unnecessary once direnv is configured in the shell and Emacs.


#+BEGIN_SRC emacs-lisp
  (require 'eglot)
  (require 'company)
  (require 'imenu-list)
  (require 'ruff-format)

  ;; Prefer CAPF-backed completion in Python buffers.
  (setq company-idle-delay 0.1)
  (setq company-minimum-prefix-length 1)
  (setq company-selection-wrap-around t)
  (setq company-tooltip-align-annotations t)

  ;; Shut down Eglot servers when the last managed buffer closes.
  (setq eglot-autoshutdown t)

  ;; Choose Python language server in priority order.
  ;; Keep global setup minimal; prefer project-specific options in
  ;; `.dir-locals.el` via `eglot-workspace-configuration`.
  (add-to-list 'eglot-server-programs
               `(python-mode . ,(eglot-alternatives
                                 '(("basedpyright-langserver" "--stdio")
                                   ("pyright-langserver" "--stdio")
                                   ("pylsp")))))
  (add-to-list 'eglot-server-programs
               `(python-ts-mode . ,(eglot-alternatives
                                    '(("basedpyright-langserver" "--stdio")
                                      ("pyright-langserver" "--stdio")
                                      ("pylsp")))))

  ;; Python IDE wiring for both classic and tree-sitter modes.
  (defun jc/python-eglot-setup ()
    "Enable Eglot, completion, and formatting in Python buffers."
    (eglot-ensure)
    (company-mode 1)
    (ruff-format-on-save-mode 1))

  (add-hook 'python-base-mode-hook #'jc/python-eglot-setup)

  ;; Slim side outline of symbols in the current buffer.
  (setq imenu-list-size 28)
  (setq imenu-list-position 'right)
  (setq imenu-list-focus-after-activation nil)
  (setq imenu-list-auto-resize t)
  (global-set-key (kbd "C-c i") #'imenu-list-smart-toggle)

  ;; Handy Eglot actions.
  (with-eval-after-load 'eglot
    (define-key eglot-mode-map (kbd "C-c C-r") #'eglot-rename)
    (define-key eglot-mode-map (kbd "C-c C-f") #'eglot-format-buffer)
    (define-key eglot-mode-map (kbd "C-c C-o") #'eglot-code-action-organize-imports))
#+END_SRC

Direnv

#+BEGIN_SRC emacs-lisp
  (require 'direnv)
  (direnv-mode)
#+END_SRC

The `.envrc` file is a per-project environment definition. When you enter a
project directory, direnv reads this file and exports its variables into your
shell (and thus into Emacs), so tools like LSP and `run-python` pick up the
correct interpreter and PATH without manual activation.

Example `.envrc` for a Python project:

#+BEGIN_SRC sh :tangle no
  source .venv/bin/activate
#+END_SRC

After creating or updating `.envrc`, run `direnv allow` once in that
project so direnv will trust and load the file.

Pytest

#+BEGIN_SRC emacs-lisp
  (require 'python-pytest)

  (defun jc/python-pytest-setup ()
    "Configure pytest keybindings for Python buffers."
    (local-set-key (kbd "C-c t t") #'python-pytest)
    (local-set-key (kbd "C-c t m") #'python-pytest-file)
    (local-set-key (kbd "C-c t f") #'python-pytest-function))

  (add-hook 'python-base-mode-hook #'jc/python-pytest-setup)
#+END_SRC
